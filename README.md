# WebStatus

Website semudah ngobrol.

## Stack

- Astro 7
- Tailwind CSS 4
- Vite plugin for Tailwind CSS

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The static output is generated in `dist/` for Cloudflare Pages.
